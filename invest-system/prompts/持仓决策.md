对 ${1:-全部持仓} 执行完整持仓决策流程（方法论：skills/holding-decision-review/SKILL.md）。严格按以下顺序委派 subagent，**不得合并角色、不得跳过空头复核**：

## 第 0 步 · 侦察（可选，数据散乱时先跑）
委派 invest-scout：收集当日行情/财务数据快照与核验（模式 A），或定向证据搜集（模式 C）。
数据少时可跳过，直接进第 1 步。

## 第 1 步 · 投研评审官（invest-analyst）
用 subagent 工具委派 invest-analyst，任务：
"对 ${1:-全部持仓} 执行假设-验证-决策流程（你的硬规则与输出格式照旧）。输出决策书草稿 + decision-record。"

## 第 2 步 · 空头复核官（invest-bear，独立上下文）
用 subagent 工具委派 invest-bear，任务只包含（不得附带主评审的调研过程）：
"以下是待证伪的假设卡、证据表和结论：\n{第1步输出}\n请出具证伪报告。"
**bear 自行取证 ≥3 条新源是硬性要求**，并审核证伪条件可触发性、给看空情景目标价。

## 第 3 步 · 风控官（invest-risk）
用 subagent 工具委派 invest-risk，任务：
"审查以下决策书与空头复核结论：\n{第1步输出}\n{第2步输出}\n出具风控审查表。"

## 第 4 步 · 合并与落盘（你本人执行）
1. 空头复核结论为"反对"且主评审坚持原决策 → 决策降级为"保持/观察"或标注【分歧】提交人工裁决，禁止静默采纳任一方
2. 风控"阻断" → 决策书标注阻断原因，输出豁免请求
3. 定稿决策书 → `{INVEST_ROOT}/stocks/{标的}/{标的}-{决策}决策书-YYYY-MM-DD.md`（含三份附件：空头证伪报告、风控审查表、decision-record）
4. **硬门槛**：`python3 skills/holding-decision-review/scripts/risk_check.py <决策书> --stock-type <类型>` 退出码 1 → 阻断不得提交
5. 留痕：`decision-log.md` 追加行 → `bubbles holding set {ticker} --state ... --decision D-...`（DB 状态流转）→ `holding/持仓汇总.md` 更新待拍板清单；**沙盒模式下买卖标注【沙盒】**
6. **上传飞书（一行命令）**：`lark-cli markdown +create --file <决策书> --as user` → 返回的 URL 附到飞书消息（非 md 文件用 `lark-cli drive +upload`）
7. 飞书推送决策汇总（≤400 字）：结论 + 依据充分性 + 多空分歧点 + 待拍板项 + **文档 URL**

**决策权在 Paulus**：所有"买入/卖出/加仓"输出止于建议，附拍板清单。

## 第 5 步 · 复核（到期自动触发，不在本次执行）
决策执行后 30 天，由 invest-reviewer 独立复盘（假设兑现 + 纪律评分）并回填 decision-log。
