对 ${@:-当前景气线索中的候选标的} 执行新股购买决策流程。总原则：**决策驱动**，产出只能是 买入 / 否决（附重新考虑条件），禁止"值得关注"。

## 第 1 步 · 候选生成与初筛（委派 invest-scout，模式 B）
从 signal-monitor 近期 🟡/🔴 信号 + industry-monitor 景气线索 + industry-deep-analysis 价值链/龙头（P1c/P1d）挖候选，按估值检查带初筛（PE 20–80x，砍掉率 ≥60%）。
候选池上限 15 只（`bubbles holding list --state watchlist` 计数），满员先淘汰最弱。有明确标的时可跳过。

## 第 3 步 · 深度尽调（证据生产）
委派或执行 `stock-buying-evaluation`：P1 基石 → P2 市场定轨 → P8 宏观压力 → P9 估值泡沫，产出 4 份文档到 `investment/stocks/{标的}/`。未上市标的换 `private-company-analysis`。

## 第 4 步 · 假设对抗（subagent 三角，独立上下文）
1. `invest-analyst`：基于尽调建**假设卡**（驱动因子+证伪条件+时间窗口+目标/止损，止损用 2×ATR 与 -20% 取宽）→ 定向验证（证据落盘 `_snapshots/`）→ 决策草稿 + decision-record
2. `invest-bear`：只给它假设卡+证据表+结论（不给调研过程）→ **自行取证 ≥3 条新源** + 证伪条件质量审核 + 看空目标价
3. `invest-risk`：风控审查（policy.yaml 硬规则 + 就绪度门）

## 第 4.5 步 · 硬门槛（程序化）
`python3 skills/holding-decision-review/scripts/risk_check.py <决策书> --stock-type <类型>`——退出码 1 = 阻断不得提交。

## 第 5 步 · 组合适配（本流程独有，逐条核算）
- 持仓数 +1 ≤ max_positions（满员必须指定**替换谁**：对比最弱持仓）
- 行业合并敞口 ≤ max_industry_pct（与现有持仓同行业合并计算）
- 买入后现金比例 ≥ min_cash_ratio；同标的 30 天内不重复建仓

## 第 6 步 · 决策落库（照搬 decision-record 三处映射）
1. 决策书 → `investment/stocks/{标的}/{标的}-买入决策书-YYYY-MM-DD.md`（附证伪报告+风控表+decision-record）
2. `decision-log.md` 追加行（否决也要记，写明重新考虑条件）
3. `bubbles holding set {ticker} --state pending_decision --decision D-... --stop-loss ... --target ... --review-date ...`（批准买入后改 holding；**沙盒模式标注【沙盒】不推真仓**）
4. **上传飞书（一行命令）**：`lark-cli markdown +create --file <决策书> --as user` → URL 附到飞书消息
4. 飞书推送待拍板清单（≤400 字）

**纪律**：bear 反对而 analyst 坚持 → 标【分歧】交人裁决；风控 block → 附豁免请求；买入后 30 天由 **invest-reviewer** 独立复盘（假设兑现 + 纪律评分回填 decision-log），自动转持仓决策流程。
