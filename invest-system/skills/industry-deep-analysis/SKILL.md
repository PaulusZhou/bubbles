# 产业深度分析

## 概述

本技能对目标行业进行系统性六维分析，产出结构化的产业投资地图，辅助投资决策。**每个分析步骤独立生成一份详细文档，按顺序依次执行。**

## 执行原则

1. **每个步骤独立输出文档** - P0/P1a/P1b/P1c/P1d/P1e 每个都生成单独文档
2. **按顺序依次执行** - 完成一个步骤再进行下一个，每个步骤完成后保存文档
3. **详细完整** - 每个文档需包含完整分析框架的所有维度
4. **数据驱动** - 以搜索数据和公开信息为依据，拒绝无根据推测

---

## 执行流程（按顺序）

### 步骤 1/6: Phase 0 - 行业录入诊断

**目标**：判断行业所处生命周期阶段，生成后续分析路线图

**执行内容**：
1. 搜索市场数据（规模/CAGR/渗透率/融资活跃度）
2. 判断生命周期阶段（导入期/成长期/成熟期/衰退期）
3. 生成定制分析路线图（推荐执行哪些P1模块）
4. 输出关键问题清单（5-8个）

**生命周期判断标准**：

| 阶段 | 渗透率 | 分析重点 |
|------|--------|----------|
| 导入期 | <15% | 可行性（是否伪需求？） |
| 成长期 | 15-40% | 规模性（天花板多高？） |
| 成熟期 | >40% | 防守性（护城河） |
| 衰退期 | 下滑 | 退出信号 |

**🔴 产出文档**：`{行业名}-P0-行业录入诊断-{YYYY-MM-DD}`

**保存位置**：`{INVEST_ROOT}/industry/{行业名}/` 目录

**本地保存命令**：
```bash
mkdir -p {INVEST_ROOT}/industry/{行业名}/
# 保存文档到本地目录
```

### 步骤 2/6: Phase P1a - 可行性验证

**适用**：导入期行业核心分析

**分析维度**（必须全部覆盖）：
1. **时空对标** - 找全球最相似历史案例，对比发展路径
2. **需求真实性** - 付费意愿/复购率/刚需判断
3. **单元经济模型（UE）** - 成本/收入/毛利率/投资回收周期测算
4. **技术就绪度（TRL 1-9）** - 当前技术成熟度评估
5. **监管与政策风险** - 政策支持/限制/监管的不确定性

**🔴 产出文档**：`{行业名}-P1a-可行性验证-{YYYY-MM-DD}`

**详细框架**：参考 [P1a-industry-feasibility.md](references/P1a-industry-feasibility.md)

---

### 步骤 3/6: Phase P1b - 市场规模测算

**适用**：成长期行业核心分析

**分析维度**（必须全部覆盖）：
1. **TAM/SAM/SOM 四层分析** - 理论/可服务/可获得市场规模
2. **三情景渗透率模型** - 悲观/中性/乐观三种假设
3. **增速驱动因素量化拆解** - 哪些因素推动增长
4. **市场增速** - CAGR和关键驱动指标
5. **时间窗口判断** - 增长高峰期预计何时到来/结束

**🔴 产出文档**：`{行业名}-P1b-市场规模测算-{YYYY-MM-DD}`

**详细框架**：参考 [P1b-industry-market-sizing.md](references/P1b-industry-market-sizing.md)

---

### 步骤 4/6: Phase P1c - 产业链分析

**适用**：所有阶段必做

**分析维度**（必须全部覆盖）：
1. **产业链全景图** - 上游/中游/下游三层结构
2. **各环节价值分布** - 毛利率/话语权强度
3. **关键瓶颈环节** - 卡脖子清单（技术/供给/成本）
4. **国产化/本土化程度** - 各环节自主可控程度
5. **风险传导路径** - 上游断供→中游受限→下游交付延迟

**🔴 产出文档**：`{行业名}-P1c-产业链分析-{YYYY-MM-DD}`

**详细框架**：参考 [P1c-industry-value-chain.md](references/P1c-industry-value-chain.md)

---

### 步骤 5/6: Phase P1d - 龙头分析

**适用**：成长期/成熟期必做

**分析维度**（必须全部覆盖）：
1. **各环节龙头梳理** - 全球龙头/中国龙头/潜在黑马
2. **核心竞争力 & 护城河** - 技术/渠道/品牌/规模等
3. **财务健康度对比** - 3-5家核心龙头主要财务指标
4. **竞争格局 & 集中度** - CR3/CR5/市场份额变化
5. **潜在黑马 & 颠覆者** - 新进入者/技术路线颠覆风险

**🔴 产出文档**：`{行业名}-P1d-龙头分析-{YYYY-MM-DD}`

**详细框架**：参考 [P1d-chain-leaders.md](references/P1d-chain-leaders.md)

---

### 步骤 6/6: Phase P1e - 竞争格局分析

**适用**：成熟期行业核心分析

**分析维度**（必须全部覆盖）：
1. **市场集中度** - CR3/CR5/CR10 市场份额
2. **护城河类型矩阵** - 六类护城河及强度
3. **价格竞争烈度** - 是否价格战、毛利率趋势
4. **产业链话语权** - 与上下游议价能力
5. **全球竞争格局** - 国际 vs 国内，竞争要素对比

**🔴 产出文档**：`{行业名}-P1e-竞争格局分析-{YYYY-MM-DD}`

**详细框架**：参考 [P1e-industry-competition.md](references/P1e-industry-competition.md)

## 待办任务闭环规则

在分析过程中识别出需要在未来跟进的事项时，**必须**使用 `bubbles` 创建定时任务，确保闭环。典型场景：
- 待特定财报/数据发布后重新评估估值或市场规模
- 待政策/会议落地后更新影响分析
- 待行业关键里程碑节点（量产、商业化等）后更新产业地图
- 定期复查行业生命周期阶段

命令示例：
```bash
# 一次性任务：指定时间执行
bubbles create --name "更新{行业名}估值" --at "2026-07-15T09:00:00" --prompt "读取 {INVEST_ROOT}/industry/{行业名}/ 目录下最新分析文档，搜索{行业名}最新财报/业绩数据，更新P1b市场规模和P1d龙头财务数据"

# 定时任务：定期复查
bubbles create --name "复查{行业名}生命周期" --schedule "0 9 1 */3 *" --prompt "读取 {INVEST_ROOT}/industry/{行业名}/ 目录下最新P0文档，搜索{行业名}最新渗透率/市场规模数据，判断生命周期阶段是否发生变化"
```

**注意**：prompt 中一律使用绝对路径和技能英文名。

## 分析完成后的收尾步骤

**每次完成行业深度分析后，必须执行以下操作**：

### 1. 更新行业监测清单

读取 `{INVEST_ROOT}/industry/行业监测清单.md`，将本次分析的行业添加进去（如已存在则更新）。

从 P0 和 P1d 分析结果中提取：
- **生命周期阶段**：从 P0 文档获取
- **追踪公司**：从 P1d 文档中提取核心梯队（3-5家）
- **产业链瓶颈**：从 P1c 文档中提取关键瓶颈环节
- **预警阈值**：根据生命周期阶段设定（导入期/成长期15%，成熟期40%）

格式参照清单中已有行业条目。
