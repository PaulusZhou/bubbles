# P0 行业录入诊断

**触发词**：「分析XX行业」「我想研究XX行业」「帮我看看XX行业」

## 流程概述

用户输入行业名 → 搜索市场数据 → 判断生命周期 → 生成路线图 → 保存到本地 → 调用深度分析

## Step 1：数据采集

优先使用 mx-skills，agent-browser 兜底：
- `mx fin_search`："{行业} 市场规模 渗透率 CAGR 研报 2025"
- `mx fin_search`："{行业} 行业发展阶段 竞争格局 头部企业 2025"
- `mx fin_search`："{行业} 政策 投资风险 商业化进展 2025"
- `mx fin_data`（可选）：上市代表公司营收/毛利率/ROE

## Step 2：生命周期判断（肖璟框架）

| 阶段 | 渗透率 | 分析重点 |
|------|--------|----------|
| 导入期 | <15% | 可行性（是否伪需求？） |
| 成长期 | 15-40% | 规模性（天花板多高？） |
| 成熟期 | >40% | 防守性（护城河） |
| 衰退期 | 下滑 | 退出信号 |

## Step 3：输出格式

**报告结构**：
1. 核心数据快照（规模/CAGR/渗透率/融资活跃度）
2. 生命周期判断（结论+依据+置信度+关键阈值）
3. 定制分析路线图（按阶段推荐重点模块）
4. 关键问题清单（5-8 个必须回答的核心问题）

## Step 4：保存到本地 investment 目录

- **存储路径**：`{INVEST_ROOT}/industry/{行业名}/`
- **文件名**：`{行业名}-P0-行业录入诊断-{YYYY-MM-DD}.md`


## Step 5：完成后

- 告知用户 Phase 0 完成，询问是否立即进行 Phase 1
- 将该行业加入监测列表（{INVEST_ROOT}/industry-watchlist.json）
