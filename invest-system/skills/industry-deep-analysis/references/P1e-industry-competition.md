# P1e 竞争格局分析

**触发词**：「分析XX行业竞争格局」「XX行业护城河」「XX行业会不会打价格战」

**适用阶段**：成熟期核心，成长期也应执行

## 分析框架

### 维度 1：市场集中度
- **CR3/CR5/CR10**：当前值 & 近 3 年趋势
- **结构类型**：垄断 / 寡头 / 分散竞争
- **趋势判断**：上升（强者恒强）or 下降（价格战风险）

- `mx fin_data`：龙头公司市占率/营收份额（最优先）

### 维度 2：护城河类型矩阵（六类）

| 护城河类型 | 行业整体强度 | 代表企业 | 可持续性 |
|------------|--------------|----------|----------|
| 规模效应 |  |  |  |
| 品牌溢价 |  |  |  |
| 网络效应 |  |  |  |
| 转换成本 |  |  |  |
| 专利/技术壁垒 |  |  |  |
| 资源/数据垄断 |  |  |  |

### 维度 3：价格竞争烈度
- ASP 近 3 年趋势（上升/平稳/下降）
- 行业整体毛利率趋势
- 产能利用率：是否过剩？
- **烈度判断**：
  - 高烈度：ASP 持续下降+毛利压缩+产能过剩
  - 中烈度：价格局部竞争，龙头毛利尚稳
  - 低烈度：价格稳定，毛利健康

- `mx fin_data`：龙头公司近 3 年毛利率趋势（最直观）

### 维度 4：产业链话语权
- 上游议价能力：供应商对整机厂的定价权
- 下游粘性：终端客户转换成本 & 复购
- 利润最集中环节（结合 1c）

### 维度 5：全球竞争格局
- 中国 vs 美国 vs 欧洲 vs 日韩各自优势
- 中国出海进展：全球份额趋势
- 中美博弈影响
