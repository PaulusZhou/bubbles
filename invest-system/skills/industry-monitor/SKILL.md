# 行业变化检测

## 概述

本技能对已入库行业进行持续监测，在高频变化中捕捉关键信号，辅助投资决策。

**使用场景**：
- 手动触发：用户询问特定行业动态
- 定时任务：cron工作日08:00每日扫描

---

### 2. 每日信号扫描（P2a）

**频率**：工作日08:00 或 手动触发

**扫描维度**（每个行业5类）：

| 类别 | 搜索关键词 | 示例 |
|------|------------|------|
| 融资 | "{行业} 融资 投资 亿元 最新" | 人形机器人 融资 亿元 |
| 政策 | "{行业} 政策 规划 监管 最新" | 新能源汽车 政策 |
| 技术 | "{行业} 技术突破 新产品 发布 量产" | AI大模型 技术突破 |
| 订单 | "{行业} 订单 合同 客户 落地" | 光模块 订单 |
| 风险 | "{行业} 风险 危机 出清 亏损 裁员" | 自动驾驶 风险 |

**信号分级**：

| 等级 | 触发条件 | 动作 |
|------|----------|------|
| 🔴 重大 | 融资>10亿/阶段变化信号/重大政策/技术里程碑 | 立即企微推送 |
| 🟡 关注 | 头部公司重要公告/行业数据更新/中型融资1-10亿 | 写入日志 |
| 🟢 普通 | 一般新闻/小额融资/常规动态 | 仅归档 |

---

### 3. 龙头动态追踪（P2b）

**频率**：每周 或 重大事件触发

**追踪对象**：监测清单中的追踪公司列表

**扫描维度**：

| 类别 | 内容 |
|------|------|
| 资本动作 | 大额融资、IPO、并购 |
| 技术产品 | 新产品发布、专利、量产进展 |
| 战略合作 | 高管变动、战略合作、产能扩张 |
| 财报 | 季报关键指标大幅偏离预期 |

**动作分级**：

| 变化类型 | 等级 | 动作 |
|----------|------|------|
| 大额融资(>5亿)/IPO/上市 | 🔴 | 立即推送 |
| 重大并购/战略合作 | 🔴 | 立即推送 |
| CEO/创始人离职 | 🔴 | 立即推送 |
| 财报大幅偏离预期 | 🔴 | 立即推送 |
| 新产品/里程碑发布 | 🟡 | 周报收录 |
| 常规季报/小额融资 | 🟢 | 周报收录 |

---

### 4. 生命周期阶段预警（P2c）

**频率**：每月 或 阈值触发

**监测指标**：

| 阶段迁移 | 触发条件 |
|----------|----------|
| 导入期→成长期 | 渗透率突破15%，连续3月融资下降，头部公司开始盈利 |
| 成长期→成熟期 | 渗透率突破40%，CAGR连续2季度下降，并购潮开始 |
| 成熟期→衰退期 | 规模连续2年负增长，替代技术渗透率>5%，头部毛利下滑 |

**输出**：
- 阶段变化时 → 生成《生命周期状态月报》+ 企微推送
- 无变化时 → 静默更新最近检查时间

---

### 5. 产业链风险监测（P2d）

**频率**：每周 或 事件触发

**监测维度**：

| 风险类型 | 搜索关键词 |
|----------|------------|
| 价格/供应 | "{关键材料} 价格 涨价 供应 短缺" |
| 断供/制裁 | "{环节} 断供 出口管制 制裁" |
| 产能变化 | "{环节} 产能 扩张 新建 停产" |

**风险评级**：

| 评级 | 触发条件 | 动作 |
|------|----------|------|
| 🔴 高危 | 断供/制裁/价格涨幅>30% | 立即推送，建议重做产业链分析 |
| 🟡 中高 | 价格涨幅10-30%/供应偏紧 | 周报标注关注 |
| 🟢 关注 | 潜在风险信号 | 周报收录 |
| ⚪ 正常 | 无明显变化 | 静默更新 |

**风险传导推演**：
当某环节评级上升时，自动推演：
```
{上游X}断供/涨价 → {中游Y}产能/成本上升 → {下游Z}交付延迟/毛利压缩
```

## 待办任务闭环规则

在监测过程中识别出需要在未来跟进的事项时，**必须**使用 `bubbles` 创建定时任务，确保闭环。典型场景：
- 🔴信号触发后需要追踪事件后续进展
- 产业链风险升级后需要重做产业链分析
- 生命周期阶段接近迁移阈值时需要定期复查
- 龙头公司IPO/重大融资后需要更新竞争格局

命令示例：
```bash
# 一次性任务：追踪🔴信号后续
bubbles create --name "追踪{公司}融资进展" --at "2026-07-15T09:00:00" --prompt "读取 {INVEST_ROOT}/industry/{行业名}/monitor/ 目录下最近信号日志，搜索{公司}最新融资/估值动态，更新P1d龙头分析"

# 定时任务：产业链风险复查
bubbles create --name "复查{行业名}产业链风险" --schedule "0 9 * * 1" --prompt "读取 {INVEST_ROOT}/industry/{行业名}/monitor/ 目录下最近信号日志，搜索{行业名}产业链关键环节最新价格/供应/产能数据，评估风险等级变化"
```

**注意**：prompt 中一律使用绝对路径和技能英文名。
