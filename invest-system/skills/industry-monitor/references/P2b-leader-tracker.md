# P2b 龙头动态追踪

**定位**：中频、精准。每周执行，聚焦已入库的龙头公司名单。

**触发**：cron 每周 / 重大事件 / 用户说「跟踪XX行业龙头进展」

---

## 追踪对象

从 watchlist.json 读取 trackedCompanies 列表：

```json
{
  "name": "公司名",
  "segment": "所处产业链环节",
  "tier": "全球龙头/国内龙头/黑马"
}
```

---

## 追踪维度（每家公司4类）

**数据来源**：

1. `eastmoney_fin_data`（结构化财务数据，最优先）
   - 查询：{公司A},{公司B} 营收 毛利率 净利润 最新季报

2. `eastmoney_fin_search`（新闻/公告/研报）
   - {公司} 融资 IPO 上市 并购 最新
   - {公司} 新产品 技术发布 量产 专利 最新
   - {公司} 战略 合作 高管 人事 最新

---

## 重要性判断

| 变化类型 | 等级 | 动作 |
|----------|------|------|
| 大额融资(>5亿)/IPO/上市 | 🔴 | 立即推送 |
| 重大并购/战略合作 | 🔴 | 立即推送 |
| CEO/创始人离职 | 🔴 | 立即推送 |
| 财报大幅偏离预期 | 🔴 | 立即推送 |
| 新产品/里程碑发布 | 🟡 | 周报收录 |
| 常规季报/小额融资 | 🟢 | 周报收录 |
