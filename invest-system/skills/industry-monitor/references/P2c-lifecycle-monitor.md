# P2c 生命周期阶段预警

**定位**：低频、阈值触发。每月执行，核心是追踪量化指标，判断阶段是否迁移。

**触发**：cron 每月 / 阈值触发

---

## 监测指标

从 watchlist.json 读取各行业的 alertThresholds 和历史数据：

- 渗透率："{行业} 市场渗透率 最新数据"
- 增速："{行业} CAGR 增长率 市场规模"
- 新进入者："{行业} 新进入企业 数量 整机厂 新玩家"
- 出清信号："{行业} 倒闭 出清 退出 兼并"（成熟/衰退期）

---

## 阶段迁移判断逻辑

### 导入期 → 成长期（触发2项以上）

- [ ] 渗透率突破 15%
- [ ] 融资数量连续3月下降
- [ ] 头部公司开始盈利
- [ ] 媒体从「概念炒作」转向「业绩讨论」

### 成长期 → 成熟期（触发2项以上）

- [ ] 渗透率突破 40%
- [ ] CAGR 连续2季度下降
- [ ] CR5 集中度上升
- [ ] 行业并购潮开始

### 成熟期 → 衰退期（触发2项以上）

- [ ] 行业总规模连续2年负增长
- [ ] 替代技术渗透率超过 5%
- [ ] 头部公司毛利率系统性下滑
- [ ] 新进入者异常增多（任何阶段）：短期内新增超过阈值

---

## 输出规则

| 情况 | 输出 |
|------|------|
| 阶段变化或阈值触发 | 生成《生命周期状态月报》+ 企微推送 |
| 无变化 | 仅更新 lastLifecycleCheck，静默完成 |
