# P2d 产业链风险监测

**定位**：中频、事件敏感。每周执行，供应链突发事件（断供/制裁/涨价）应立即触发。

**触发**：cron 每周 / 用户问「XX行业供应链有没有风险」

---

## 追踪对象

来自深度分析（P1c）识别的 chainBottlenecks 列表：

```json
{
  "环节": "关键材料/技术",
  "风险等级": "高/中/低",
  "国产化率": "X%"
}
```

---

## 监测维度（4类）

优先使用 eastmoney_fin_search（对政策/制裁/价格有专项信源筛选）：

| 风险类型 | 搜索关键词 |
|----------|------------|
| 价格/供应 | "{关键材料} 价格 涨价 供应 最新" |
| 断供/制裁 | "{关键环节} 断供 短缺 供应链紧张" |
| 出口管制 | "{行业} {关键技术} 出口管制 制裁 限制" |
| 产能变化 | "{关键环节} 产能 扩张 新建 停产" |

---

## 风险评级逻辑

| 评级 | 触发条件 | 动作 |
|------|----------|------|
| 🔴 高危 | 断供/制裁/价格涨幅>30% | 立即推送，建议重新分析产业链 |
| 🟡 中高 | 价格涨幅10-30%/供应偏紧 | 周报收录，标注关注 |
| 🟢 关注 | 潜在风险信号/政策动向 | 周报收录 |
| ⚪ 正常 | 无明显变化 | 静默更新 |

---

## 风险传导评估

当某环节评级上升时，自动推演影响链：

```
{上游X}断供/涨价 
  → 影响 {中游Y} 产能/成本上升 X% 
  → 影响 {下游Z} 交付延迟/毛利压缩
```

## 紧急推送格式

发现高危风险时立即企微推送：

```
产业链风险预警
行业：{行业}
环节：{环节}
事件：{描述}
评级变化：高危

传导影响预估：{一句话}

建议：是否立即重新分析产业链？[Y/N]
```
