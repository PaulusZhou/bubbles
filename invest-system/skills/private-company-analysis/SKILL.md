# 非上市公司深度分析

## 概述

本技能对未上市目标公司进行系统性深度调研，产出1份完整档案。由于非上市公司缺乏公开股价/PE等市场数据，分析重心放在基本面质量与竞争格局上，为投资决策（一级市场、产业链关联投资、或作为上市公司的竞对参照）提供依据。

**核心差异**（vs 上市公司 stock-buying-evaluation）：
- 无股价/PE/PB等市场估值数据 → 用融资轮次/估值替代
- 无SEC Filings/季报 → 用新闻、融资材料、行业报告拼图
- 竞争格局权重提升 → 非上市竞对是该领域的主要玩家
- 增加"IPO/退出展望"维度 → 一级市场投资需要退出路径

---

## 数据校验规则（必须遵守）

### 时效性要求
- **融资信息**：必须确认最近一轮融资的时间与金额
- **财务数据**：非上市公司财务不透明，所有数据必须标注来源和时效
- **市场份额**：优先使用行业报告（IDC/Gartner/赛迪等），辅以新闻估算

### 校验流程
1. 搜索"公司名 最新融资 估值 2026"
2. 搜索"公司名 市场份额 行业报告"
3. 写入文档前标注每条数据来源（如"据2025年IDC报告"、"据36氪2026年4月报道"）
4. 无法验证的数据标注"未经验证"或"估算值"

### 常见错误避免
- ❌ 使用旧融资轮次数据
- ❌ 将新闻稿宣传数据当作事实
- ❌ 忽略非上市竞对（非上市领域的竞对大多也未上市）
- ❌ 不同来源数据矛盾时不标注

## 工作流程

### 六维分析

| 维度 | 分析要点 |
|------|----------|
| 治理结构 | 创始人背景、团队稳定性、股东构成、融资历程 |
| 商业壁垒 | 护城河类型、护城河深度、反脆弱性 |
| 竞争格局 | 市场份额（含非上市竞对）、国内外对比（核心维度） |
| 财务健康 | 营收规模与增速、盈利状态、现金流、烧钱速率 |
| 周期维度 | 行业阶段、宏观敏感度、竞争终局 |
| 退出展望 | IPO可能性、并购预期、对上市投资的影响 |

---

### 1. 治理结构 (The Soul)
- **创始人画像**: 背景（学术/产业/连续创业）、过往业绩、技术信仰 vs 商业驱动
- **核心团队**: 关键技术/业务负责人背景，团队完整度
- **股东构成**: 创始人持股、VC/PE机构、产业资本、国资背景
- **融资历程**: 每轮时间/金额/估值/领投方，判断资本认可度趋势

### 2. 商业壁垒 (The Engine)
- **模式简述**: 核心盈利逻辑，客户付费意愿来源
- **护城河分析**: 技术壁垒/数据壁垒/网络效应/牌照壁垒/规模效应
- **反脆弱性**: 行业下行期是否有逆势扩张能力

### 3. 竞争格局 (The Arena) — 核心维度
- **市场份额**: 目标公司在核心市场的占有率，**必须列出所有主要竞对的市场份额，不论是否上市**。非上市领域竞对多为未上市公司，需通过行业报告、融资信息等渠道估算
- **国内竞争**: 国内市场前5名竞对排名及份额，分析份额变化趋势（集中/分散）。特别关注：同为非上市的竞对是否获得更多资本支持
- **国际对比**: 全球市场主要参与者及份额，国内外技术/产品差距。国外竞对是否可能进入国内，或目标公司出海的可行性
- **份额趋势**: 近2-3年份额变化方向，判断 α型(份额提升) / β型(份额稳定) / 危险型(份额被侵蚀)

### 4. 财务健康 (The Fuel)
- **营收规模与增速**: 最新年度营收及同比增速（非上市公司可能只有估算值）
- **盈利状态**: 是否盈利、盈亏平衡点预测
- **现金流**: 经营性现金流状况、账上现金储备
- **烧钱速率**: 月度/季度烧钱额、当前现金可支撑时间（Runway）

### 5. 周期维度 (The Cycle)
- **行业所处阶段**: 导入期/成长期/成熟期/衰退期
- **宏观敏感度**: 政策（特别是监管风险）、利率、地缘政治
- **竞争终局**: 3-5年后行业格局预判，目标公司是否还能留在牌桌上

### 6. 退出展望 (The Exit)
- **IPO可能性**: 是否有IPO计划/辅导/申报，所在板块对盈利的要求，市场环境
- **并购预期**: 是否可能被上市公司或产业资本收购，潜在买家
- **对上市投资的影响**: 如果是上市公司竞对，该非上市公司的发展如何影响相关上市公司的投资逻辑（增强/削弱/无关）

## 待办任务闭环规则

在分析过程中识别出需要在未来跟进的事项时，**必须**使用 `bubbles` 创建定时任务，确保闭环。典型场景：
- 公司下一轮融资/估值变化后需要更新评估
- 公司IPO进程关键节点需要跟踪
- 竞对公司重大动态需要重新评估竞争格局
- 公司产品量产/商业化里程碑需要验证

命令示例：
```bash
# 一次性任务：追踪下一轮融资
bubbles create --name "追踪{公司名}融资" --at "2026-09-01T09:00:00" --prompt "搜索{公司名}最新融资/估值动态，读取 {INVEST_ROOT}/stocks/{公司名}-PRIVATE/ 目录下深度档案，更新融资历程和竞争格局章节"

# 定时任务：追踪IPO进程
bubbles create --name "追踪{公司名}IPO" --schedule "0 9 1 */2 *" --prompt "搜索{公司名}最新IPO进展/辅导/申报动态，读取 {INVEST_ROOT}/stocks/{公司名}-PRIVATE/ 深度档案，更新退出展望章节"
```

**注意**：prompt 中一律使用绝对路径和技能英文名。
