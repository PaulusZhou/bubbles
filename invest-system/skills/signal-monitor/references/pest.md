# PEST 深读框架（会议/重大事件解读）

> 适用：政治局会议、经济工作会议、两会、关税事件、地缘冲突等系统性事件。
> 产出命名：`{事件名}-PEST-YYYY-MM-DD.md` → `investment/events/`

## 结构（四步）

### 1. PEST 四维拆解
| 维度 | 关键问题 |
|---|---|
| **P 政策** | 表态的定调变化（措辞对比上一次）？新增/退出哪些产业政策？执行力度与节奏？ |
| **E 经济** | 对增长/通胀/流动性（利率、降准、财政）的含义？数据指向？ |
| **S 社会** | 就业、消费、人口、舆情层面的二阶影响？ |
| **T 技术/国际** | 技术管制、贸易条件、汇率与跨境资本？ |

### 2. 预期差分析（最重要）
- 市场此前定价了什么 vs 实际落地了什么 → **超预期 / 符合预期 / 低于预期** 逐条标注
- 措辞级对比：与上一次会议/声明的原文差异（"支持"→"大力支持"这类变化）

### 3. 产业链传导映射
| 传导路径 | 受益/受损环节 | 关键标的（含观察池候选） |
|---|---|---|
| 直接受益（补贴/订单） | … | … |
| 成本端影响（税/汇率/原料） | … | … |
| 需求端影响（财政/消费） | … | … |

### 4. 投资动作接口（必须给结论）
- 对**每只持仓**：影响哪个驱动因子？是否触发证伪条件？→ 是则触发 `holding-decision-review`
- 对**候选池**：是否产生新线索？→ 提交新股决策流程
- 整体仓位含义：进攻/防守/不变（一句话）

## 硬规则
- 所有引用带来源 + 日期；政策措辞引用原文，不转述
- 预期差判断必须附"市场此前预期"的证据（研报/走势/利率期货等），不许凭感觉
- 无结论不落笔：第 4 节禁止写"持续关注"
