# 新股买入前尽调（证据生产者）

## 概述

本技能对目标公司做买入前系统性尽调，产出 4 份独立文档。**本技能不出决策**——买入/否决由 holding-decision-review 骨架（假设-验证-就绪度门）产出 decision-record；P5 决策职能已废除并入该骨架。

**尽调流程**：基本面 → 市场阶段 → 宏观敏感度 → 估值合理性

---

## 数据校验规则（必须遵守）

### 时效性要求
- **股价/PE**：必须获取**当日或前一日**的最新数据
- **财报数据**：使用最新季度/年报数据

### 校验流程
1. 搜索"公司名 最新股价 PE 2026年3月"
2. 找到最新日期的数据
3. 写入文档前核对：PE在20-80倍区间为正常范围
4. 如果搜索结果有多个日期，优先使用最新日期

### 常见错误避免
- ❌ 使用旧日期的数据
- ❌ 不验证PE合理性
- ❌ 不同来源数据矛盾时不复核

## 工作流程

### P1: 个股基石调研

**目的**：建立深度基本面档案

**六维分析**：

| 维度 | 分析要点 |
|------|----------|
| 治理结构 | 掌舵人属性、团队稳定性、机构持股 |
| 商业壁垒 | 护城河类型、护城河深度，反脆弱性 |
| 竞争格局 | 市场份额（含非上市竞对）、国内外对比 |
| 财务健康 | 现金流、ROIC、北极星指标 |
| 周期维度 | 行业阶段、宏观敏感度、竞争终局 |
| 博弈维度 | Bull Case、Bear Case、预期差 |

**产出文档**：`{公司名}-P1-基石档案-{日期}`（如 `宁德时代-P1-基石档案-2026-04-22`）

---

### P2: 市场定轨

**目的**：判断PVE（共识趋势）还是PVP（博弈）

**PVE特征**：业绩驱动、增量资金、业绩兑现
**PVP特征**：情绪驱动、存量博弈、利好出货

**产业-市场映射**：

| 产业阶段 | 市场特征 | 策略 |
|----------|----------|------|
| 导入期 | PVP | SOP 2或观望 |
| 成长期早期 | PVP→PVE | SOP 2转SOP1 |
| 成长期中期 | PVE | SOP 1 |
| 成熟期 | PVE | SOP 1收息 |
| 衰退期 | PVP | SOP 2或回避 |

**产出文档**：`{公司名}-P2-市场定轨-{日期}`（如 `宁德时代-P2-市场定轨-2026-04-22`）

---

### P8: 宏观压力测试

**目的**：评估宏观因素对持仓的影响

**维度**：
- 贴现率敏感度
- 业务传导机制（成本端/需求端）
- 避险属性

**产出文档**：`{公司名}-P8-宏观压力测试-{日期}`（如 `寒武纪-P8-宏观压力测试-2026-04-19`）

---

### P9: 估值泡沫度量

**目的**：判断当前价格是否合理，给出分档建仓建议

**方法**：反向DCF × 相对估值交叉验证（7步法）
1. 估值快照：PE/PB/PS/PEG/EV-EBITDA 多指标历史分位 + 生命周期匹配
2. 反向DCF：隐含CAGR矩阵 + 增长率拆解验证 + DCF避坑检查（5项）
3. Reality Check：行业天花板 + 历史对标 + 竞争格局
4. 相对估值：同业对比 + 质地溢价/折价调整 + 相对估值避坑检查（5项）
5. 泡沫度量：5维加权评分(1-10) + DCF×相对估值一致性检验
6. 安全边际：敏感度矩阵 + 盈亏比 + 折扣力度（达标线5-6折）
7. 买入建议：分档建仓价格与仓位

**产出文档**：`{公司名}-P9-估值泡沫-{日期}`（如 `小米集团-P9-估值泡沫-2026-04-03`）

---

### P5（已废除）

原"买入冷静分析/最终决策"职能并入 `holding-decision-review`（假设卡 + 决策就绪度门 + decision-record）。FOMO 自检保留为决策骨架的预验尸步骤。

## 命名规范（必须遵守）

**Ticker 格式**：`{市场}.{代码}`，如 `HK.01810`、`SH.688256`、`SZ.300750`、`US.NFLX`
- 港股：`HK.{5位代码}`（如 `HK.01810`、`HK.00700`）
- A股沪市：`SH.{6位代码}`（如 `SH.688256`、`SH.603662`）
- A股深市：`SZ.{6位代码}`（如 `SZ.300750`、`SZ.002050`）
- 美股：`US.{代码}`（如 `US.NFLX`、`US.AAPL`）

**目录名**：`{公司名}-{Ticker}`，如 `小米集团-HK.01810`、`寒武纪-SH.688256`

**文件名**：`{公司名}-P{X}-{模块名}-{YYYY-MM-DD}.md`，如 `小米集团-P1-基石档案-2026-04-03.md`

❌ 错误：`688256.SH-P1-...`（纯代码无公司名）、`HK.01810-P1-...`（文件名缺少公司名）
✅ 正确：`寒武纪-P1-基石档案-2026-04-19.md`

## 待办任务闭环规则

在分析过程中识别出需要在未来跟进的事项时，**必须**使用 `bubbles` 创建定时任务，确保闭环。典型场景：
- 当前估值偏高，等待回调至目标买点后重新评估
- 待下一份财报发布后验证业绩逻辑
- 待行业关键数据发布后更新估值模型
- 宏观环境变化后需要重新做压力测试

命令示例：
```bash
# 一次性任务：财报发布后更新估值
bubbles create --name "更新{公司名}估值" --at "2026-08-15T09:00:00" --prompt "搜索{公司名}最新季度财报数据，读取 {INVEST_ROOT}/stocks/{公司名}-{Ticker}/ 目录下P1和P9文档，更新估值模型和泡沫度量"

# 一次性任务：等待股价回调至目标区间
bubbles create --name "检查{公司名}买点" --at "2026-07-20T09:00:00" --prompt "使用 futuapi 技能获取 {Ticker} 最新股价，读取 {INVEST_ROOT}/stocks/{公司名}-{Ticker}/ 目录下P5和P9文档，判断当前是否到达分档建仓价格区间"
```

**注意**：prompt 中一律使用绝对路径和技能英文名。
