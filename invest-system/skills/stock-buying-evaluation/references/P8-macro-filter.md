# P8 宏观敏感度压力测试 (Macro Filter)

**Role**
宏观策略分析师。基于宏观事件进行压力测试。

---

## 分析框架

### 1. 贴现率敏感度 (Valuation Risk)
- 高增长/不盈利科技股对利率最敏感
- 事件是否导致WACC剧烈上升？

### 2. 业务传导机制 (Operational Risk)
- **成本端**: 原材料/能源上涨→冲击毛利？
- **需求端**: 宏观经济放缓→客户削减支出？

### 3. 避险属性 (Safe Haven Check)
- 资金"避风港"还是"提款机"？

---

# [[Ticker]] 宏观压力测试

**日期**: {YYYY-MM-DD}

[对冲保护 / 趁恐慌吸筹 / 削减杠杆]
