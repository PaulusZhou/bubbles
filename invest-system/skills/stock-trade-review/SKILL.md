## 待办任务闭环规则

在复盘过程中识别出需要在未来跟进的事项时，**必须**使用 `bubbles` 创建定时任务，确保闭环。典型场景：
- 复盘发现的SOP优化点需要在新交易中验证
- 同行业/同逻辑的股票需要用修正后的框架重新评估
- 违规项需要设定定期自查提醒

命令示例：
```bash
# 一次性任务：验证SOP优化
bubbles create --name "验证{行业}类股票SOP优化" --at "2026-08-01T09:00:00" --prompt "读取 {INVEST_ROOT}/review/ 目录下复盘文档中的改进动作，搜索{行业}最新投资机会，使用优化后的SOP框架进行分析"

# 定时任务：纪律自查
bubbles create --name "交易纪律月度自查" --schedule "0 9 1 * *" --prompt "读取 {INVEST_ROOT}/review/ 目录下近期复盘文档，汇总待改进项，检查当前持仓和近期交易是否遵守修正后的纪律规则"
```

**注意**：prompt 中一律使用绝对路径和技能英文名。
